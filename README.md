# ことのはダンジョン

AIがゲームマスターを務める、ブラウザで遊べるテキストローグライク。

**何を書いてもいい。でも、結果はダイスが決める。**

行動は自由入力。ゲームに組み込まれたAI（ブラウザ内で動く小型LLM）がその行動を「どの能力値で・どの難易度で判定するか」に変換し、成否はコードがd20で決めます。HP・アイテム・敵の状態はすべてコードが管理するので、「伝説の剣を見つける」と書いてもズルはできません。

## AIはブラウザの中で動く

- [WebLLM](https://github.com/mlc-ai/web-llm) を使い、Qwen3.5 をあなたのPCのGPU（WebGPU）で動かします
- クラウドのAPIは使いません。APIキーも不要で、入力した行動が外部に送られることはありません
- 初回だけ、モデルとWebLLM本体のダウンロードが必要です。2回目以降はブラウザに保存されたものを使います
- WebGPU が使えないブラウザでは、簡易ルールでAIの代わりをする**デモモード**で遊べます

モデルは設定で選べます（大きいほど語りが上手ですが、重くなります）。

- 軽量: Qwen3.5 0.8B（GPUメモリ 約1.6GB）
- 標準: Qwen3.5 2B（約2.3GB）← 既定
- 高品質: Qwen3.5 4B（約3.9GB）

## 遊び方

WebGPU は安全なページ（`https://` か `localhost`）でしか動かないため、ローカルサーバー経由で開いてください。

```
python3 -m http.server 8000
# → ブラウザで http://localhost:8000/ を開く
```

職業を選んで冒険開始。最奥（B5）の番人を倒して「禁書」を取り戻せば勝利です。

## ルール

- 判定: **d20 + 能力値補正 ≧ 難易度（DC）**。出目20は大成功（ダメージ2倍）、1は大失敗
- 難易度: 易 6 / 普通 10 / 難 14 / 至難 18。AIは段階だけを選び、数値はコードが決める
- 攻撃の難易度は、敵ごとの防御値でコードが決める
- **工夫ボーナス**: 部屋にある物をうまく使うと「有利」（d20を2回振って高い方）。各物は1回限り
- NPCの好感度が上がると、アイテムや番人の弱点（番人への判定+2）を教えてくれる
- 判定のいらない行動（difficulty: none）では、ダメージや入手などの強い効果は起こらない

## しくみ

1ターンにつき、AIの呼び出しは1回だけです。AIは次の3つをまとめて返し、コードがダイスの結果に合う方の語りを表示します。

- 裁定（JSON Schema で出力の形を強制）
- 成功時の語り
- 失敗時の語り

AIの出力はそのまま信じず、コードで検証します。

- 存在しない物・敵・アイテムは無視（小さいモデル向けに、IDの代わりに名前で書かれていても照合する）
- 「成功したのにプレイヤーが傷つく」「失敗したのに敵が傷つく」といった矛盾した効果は削除
- NPCの秘密は、好感度が1以上になるまでAIにも渡さない
- AIの応答が壊れていた場合は、そのターンだけ簡易ルールで判定する
