# ことのはダンジョン

AIが行動を読み取る、ブラウザで遊べるテキストローグライク。

**何を書いてもいい。でも、結果はダイスが決める。**

行動は自由に文章で入力します。ゲームに組み込まれたAIが「どんな行動か」を読み取り、成否はコードがd20で決めます。HP・アイテム・敵の状態はすべてコードが管理するので、「伝説の剣を見つける」と書いてもズルはできません。

## AIのしくみ

- 日本語の文章を理解する小さなAIモデル [ruri-v3-30m](https://huggingface.co/cl-nagoya/ruri-v3-30m)（Apache-2.0、約44MB）を、[Transformers.js](https://github.com/huggingface/transformers.js) でブラウザの中（CPU）で動かします
- **GPUもAPIキーも不要**です。入力した行動が外部に送られることもありません
- 初回だけモデルをダウンロードし、2回目以降はブラウザに保存されたものを使います
- AIは行動ごとの例文（`INTENTS`）と入力の意味の近さを比べ、「攻撃」「会話」「罠の解除」などのどれかを判定します。例文を足すほど言い回しに強くなります
- 「刺す」と「ぶっ刺す」、「挨拶する」と「こんにちはと声をかける」のような言い換えも、同じ行動として読み取れます
- ゲームと関係ない入力（「ラーメンが食べたい」など）は、ターンを消費せずに聞き直します
- 部屋にある物や敵の名前は、別名（「シャンデリア」→「照明」「鎖」など）も含めて文中から探します
- 語りの文章は、状況に合わせて用意した文章から選びます。NPCは性格に合った台詞を話します
- AIを読み込めない環境では、キーワードだけで判定する**簡易モード**で遊べます

## 遊び方

`index.html` をブラウザで開くだけで遊べます。他の人に遊んでもらうなら、GitHub Pages などに置くのが簡単です（サーバー側の処理は不要）。

ローカルで配信する場合の例：

```
python3 -m http.server 8000
# → http://localhost:8000/
```

職業を選んで冒険開始。最奥（B5）の番人を倒して「禁書」を取り戻せば勝利です。

入力の例：

- 「シャンデリアを落としてスライムを押し潰す」（部屋の物を使うと有利）
- 「オルガに丁寧に挨拶する」「番人の弱点を知っているか聞く」
- 「罠を慎重に外す」「扉の文字を読む」
- 「敵の動きを観察する」（敵の特徴や罠の正体がわかる）

## ルール

- 判定: **d20 + 能力値補正 ≧ 難易度（DC）**。出目20は大成功（ダメージ2倍）、1は大失敗
- 難易度: 易 6 / 普通 10 / 難 14 / 至難 18
- 攻撃の難易度は、敵ごとの防御値で決まる
- **工夫ボーナス**: 部屋にある物を使うと「有利」（d20を2回振って高い方）。各物は1回限り
- NPCと仲良くなると、アイテムや番人の弱点（番人への判定+2）を教えてくれる

## 判定の流れ

1. AIが入力の意図を読み取る（攻撃・魔法・物を使う・回避・会話・威嚇・探索・観察・罠の解除・解読・持ち物・移動・休憩・不可能な行動）
2. コードが、意図と部屋の状況（敵・物・罠・NPC）から判定内容を組み立てる
3. コードが判定内容を検証してからダイスを振り、効果を適用する
