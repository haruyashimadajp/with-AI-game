# ことのはダンジョン

AIがゲームマスターを務める、ブラウザで遊べるテキストローグライク。

**何を書いてもいい。でも、結果はダイスが決める。**

行動は自由入力。AI（Claude）がその行動を「どの能力値で・どの難易度で判定するか」に変換し、成否はコードがd20で決めます。HP・アイテム・敵の状態はすべてコードが管理するので、「伝説の剣を見つける」と書いてもズルはできません。

## 遊び方

1. `index.html` をブラウザで開く（ファイル1つだけで動きます）
2. 「設定」で Anthropic APIキーを入れる
   - キーなしでも、簡易ルールでAIの代わりをする**デモモード**で遊べます
3. 職業を選んで冒険開始。最奥（B5）の番人を倒して「禁書」を取り戻せば勝利

ローカルで配信する場合の例：

```
python3 -m http.server 8000
# → http://localhost:8000/
```

## ルール

- 判定: **d20 + 能力値補正 ≧ 難易度（DC）**。出目20は大成功（ダメージ2倍）、1は大失敗
- 難易度: 易 6 / 普通 10 / 難 14 / 至難 18。AIは段階だけを選び、数値はコードが決める
- 攻撃の難易度は、敵ごとの防御値でコードが決める
- **工夫ボーナス**: 部屋にある物をうまく使うと「有利」（d20を2回振って高い方）。各物は1回限り
- NPCの好感度が上がると、アイテムや番人の弱点（番人への判定+2）を教えてくれる
- 判定のいらない行動（difficulty: none）では、ダメージや入手などの強い効果は起こらない

## しくみ

1ターンにつき、AIの呼び出しは1回だけです。AIは次の3つをまとめて返し、コードがダイスの結果に合う方の語りを表示します。

- 裁定（JSON Schema による構造化出力）
- 成功時の語り
- 失敗時の語り

AIの出力はそのまま信じず、コードで検証します。

- 存在しない物・敵・アイテムのIDは無視
- 「成功したのにプレイヤーが傷つく」「失敗したのに敵が傷つく」といった矛盾した効果は削除
- NPCの秘密は、好感度が1以上になるまでAIにも渡さない

## APIキーについて

- キーはブラウザの localStorage にだけ保存され、`api.anthropic.com` にのみ送信されます
- ブラウザから直接APIを呼ぶため、**自分専用で遊ぶ前提**です。公開サーバーに置いて他人に遊ばせる場合は、キーを隠すプロキシ（Cloudflare Workers など）が必要です
- 既定のモデルは Claude Opus 5.5（effort: low）。設定で Sonnet 5.5 / Haiku 5.5 に切り替えられます
